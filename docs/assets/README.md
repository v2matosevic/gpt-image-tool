# Public artwork manifest

Created for the gpt-image-tool source launch on September 5, 2026.

## Generated samples

- `paper-sculpture.png`: orange folded-paper sculpture. Generated by this repository's `generate_image` MCP tool with the subscription backend and `product-studio` preset.
- `fox-mascot.png`: folded-paper fox. Generated by the same tool with the `mascot` preset. Transparency was produced by the tool's chroma-key pipeline.
- Each `.png.json` is the tool-written specification, including the full prompt, settings, and revised prompt. They were reviewed for private paths and credentials before publication. No external reference images were supplied.

These are AI-generated examples. They do not depict real products, customers, or endorsements. They demonstrate observed output on one account, not guaranteed results for every installation.

Both requests specified 1024×1024; both returned 1254×1254. The sculpture is opaque; the fox has an alpha channel with fully transparent and fully opaque pixels. The sidecars record requested settings, not measured dimensions. This is why the setup guidance calls for inspecting actual outputs.

## Designed layouts

`github-banner.png` (1280×640) and `workflow.png` (1600×920) are deterministic editorial layouts from `scripts/launch-assets.mjs`. Typography is rendered locally, with the generated samples placed into the layouts. The workflow request panel is illustrative, not a captured client session.

Social deliverables live in [../launch](../launch/README.md). Rebuild all layouts with `npm run assets:launch` after installing dependencies. This command makes no model requests. It uses Arial with system sans-serif fallbacks, so line metrics can vary across machines; visually check rebuilt output.
