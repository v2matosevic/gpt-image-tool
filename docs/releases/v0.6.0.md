# gpt-image-tool 0.6.0: logo kits and brand boards

Take an image brief through logo exploration, exact typography and a complete
website/social branding package inside your coding agent.

## What changed

- `preview_image_request` compiles the actual request without credentials or image
  usage. Structured briefs, exact brand settings and role-labelled references give
  each input one job. Palette/logo references supply colors without sending their
  artwork into unrelated scenes.
- `export_logo_kit` builds mark, wordmark, horizontal and stacked layouts from
  supplied artwork. It exports PNG/WebP and genuine SVG where every component is
  vector, plus favicons, Apple/app/maskable icons, social images, manifests and a
  review sheet. New typeset names require an explicit request. Multicolor marks
  need supplied mono artwork unless silhouette conversion is explicitly selected.
- `create_brand_board` combines exact color swatches, static font-file specimens,
  logo artwork and supplied or explicitly generated tiles. Editorial and grid
  layouts produce PNG, a self-contained SVG presentation, source records and
  CSS/JSON tokens.
- Static TTF/OTF/WOFF outlines and SVG logos work in overlays and social cards.
  Missing glyphs are checked before boards/carousels generate their imagery.
- Seven branding presets bring the catalog to 77 presets and 23 modifiers. Logo
  concepts can be reviewed together on a labelled contact sheet.
- Masked edits preserve original pixels outside the editable area by default.
  Output metadata reports actual dimensions, format and transparency. Alpha
  scaling/compositing and carousel accent consistency are corrected.
- Compatible fast-uri and ip-address dependency updates address reported advisories.

## Install or upgrade

Use Node.js 22.18 or newer:

```sh
git clone --branch v0.6.0 https://github.com/v2matosevic/gpt-image-tool.git
cd gpt-image-tool
npm ci
npm run build
npm run smoke:mcp
```

Existing users: follow the [upgrade instructions](https://github.com/v2matosevic/gpt-image-tool/blob/v0.6.0/docs/SETUP.md#upgrade-an-existing-installation), then reconnect MCP. The server reports `0.6.0` and exposes 13 tools. The default `npm ci` includes the `sharp` renderer needed for branding exports. No global install is required.

Try the offline preview:

```sh
node dist/cli.js --subject "an abstract leaf mark" --preset logo-mark --preview
```

Runnable offline logo-kit and board specifications are in
[`test/fixtures`](https://github.com/v2matosevic/gpt-image-tool/tree/v0.6.0/test/fixtures).
Use your own static font files for real brand work. Read the
[branding guide](https://github.com/v2matosevic/gpt-image-tool/blob/v0.6.0/docs/BRANDING.md)
for MCP calls and [view the output examples](https://github.com/v2matosevic/gpt-image-tool/blob/v0.6.0/docs/assets/README.md#branding-showcase-v060).

## Behavior changes and limits

Masked edits now return PNG at the original dimensions by default, preserving
opaque-mask pixels exactly. Use `preserve_unmasked: false` (CLI
`--no-preserve-unmasked`) to retain the full model redraw. The mask's alpha controls
the transition; no feather is added outside the editable area.

Declared `brand.colors` supersede older profile `style.color` hints. Explicit
per-call colors still win. Sidecars store actual output information, while replay
remains another nondeterministic generation.

Generated logo concepts remain raster. An SVG presentation can embed raster tiles;
it is not an all-vector logo master. Supplied SVG logos must be self-contained and
outlined; unsupported or active content is rejected. Font files require covered
glyphs and static instances. WOFF2, variable axes, certified complex-script shaping,
automatic vector tracing and print color certification are not included.

The subscription backend remains the default, with server-selected rendering and
account-dependent usage. It never silently switches to paid API billing. Flare and
Sunburst selection still requires the explicit API backend. This release makes no
new claim about subscription renderer identity.

## Verification

The implementation passed 115 offline tests and a real stdio MCP check covering
the 13-tool catalog and calls to all three new tools. Provider requests in tests
are mocked. CLI fixtures, logo variants, both board layouts and website/social
icons were checked locally. Claude Opus 5.5 reviewed the implementation; all
reported blockers were corrected before release preparation.

A bounded live sample used exactly three sequential, low-quality subscription
requests: two logo concepts and one material study. Saved outputs were inspected.
This establishes sampled behavior, not consistent design quality across all brands
or every new preset. No paid API generation was run.

Exact release commit, clean-install results, CI, downloaded-archive verification
and local installation state are recorded in the
[release verification](https://github.com/v2matosevic/gpt-image-tool/blob/main/docs/RELEASE-VERIFICATION.md).
The source is public and MIT licensed. GitHub supplies source archives; no npm
package or standalone binary is published.
