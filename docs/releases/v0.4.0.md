# gpt-image-tool 0.4.0

GPT-6 Astra now directs subscription image generation and proofreads the resulting images. The explicitly selected paid Images API backend now defaults to GPT Image 2.

## Changes

- Subscription routing: `gpt-5.6-terra` → `gpt-6-astra`.
- Vision proofreading: `gpt-5.6-terra` → `gpt-6-astra`.
- Paid API generation and editing: `gpt-image-1` → `gpt-image-2`.
- Subscription requests require the image tool to run, reducing text-only responses.
- API edits send the requested output format, matching generation requests.
- The CLI health check displays configured models and distinguishes a valid login from verified image access.
- Codex setup includes separate startup and image-call timeouts.

All existing model overrides remain supported. The subscription endpoint selects its underlying image renderer; using Astra does not certify a particular GPT Image version. OpenAI's current image guide names GPT Image 2. This release does not claim support for an unverified "Image 2.5" model.

## Install or upgrade

Use Node.js 22.18 or newer. For a new installation:

```sh
git clone --branch v0.4.0 https://github.com/v2matosevic/gpt-image-tool.git
cd gpt-image-tool
npm ci
npm run build
npm run smoke:mcp
```

Connect your client using the [setup guide](https://github.com/v2matosevic/gpt-image-tool/blob/v0.4.0/docs/SETUP.md). Existing users should follow [upgrade instructions](https://github.com/v2matosevic/gpt-image-tool/blob/v0.4.0/docs/SETUP.md#upgrade-an-existing-installation), then reconnect their MCP server. Remove an old model override if you want the new default.

Codex image server settings:

```toml
startup_timeout_sec = 120
tool_timeout_sec = 600
```

Add these inside the existing `[mcp_servers.gpt-image]` section.

The tagged source passed [all four CI jobs](https://github.com/v2matosevic/gpt-image-tool/actions/runs/34127181942): Node 22 on Windows, macOS and Linux, plus Node 24 on Linux. A separate clean installation passed locally, and the downloaded GitHub source archive matched all 104 files in the tagged commit. The publication scan reported no credential-pattern findings in 294 historical blobs.

The repository remains public and MIT licensed. Install from the tagged source or GitHub's source archives; no npm package is published. The experimental subscription backend uses account allowance through an undocumented endpoint and remains account-dependent. API billing is enabled only by explicitly selecting the API backend. Upgrading does not change that choice.
