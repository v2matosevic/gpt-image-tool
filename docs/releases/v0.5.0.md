# gpt-image-tool 0.5.0: Flare and Sunburst

Choose GPT Image 2.5 Flare for faster generation or Sunburst for editing precision through the explicitly selected, separately billed OpenAI API backend.

## Changes

- Update `sharp` to 0.35.4 or newer within its compatible patch range, addressing its bundled libheif security advisory (GHSA-rgj7-g3m4-5g8c).

- Select `flare` or `sunburst` per CLI/MCP call or project profile. The API default is now Sunburst; existing environment model overrides remain supported.
- Use `xhigh` and `max` quality alongside `auto`, `low`, `medium` and `high` for Image 2.5 API requests.
- Preserve the renderer through reference edits, masks, upscales, series, social cards/carousels, generated web sources and model-assisted cutouts.
- Save the requested renderer in image sidecars so replay retains the choice. Explicit per-call values override inherited defaults.
- Reject explicit model choices on the subscription backend before sending requests. A live negative control returned an image for a nonexistent renderer name, so successful subscription output does not establish model selection. No automatic switch to paid billing occurs.

The subscription backend remains the default and continues using Astra to direct its server-selected image renderer. This release does not claim that subscription users can select either Image 2.5 model.

## Install or upgrade

Use Node.js 22.18 or newer:

```sh
git clone --branch v0.5.0 https://github.com/v2matosevic/gpt-image-tool.git
cd gpt-image-tool
npm ci
npm run build
npm run smoke:mcp
```

Existing users: follow the [upgrade instructions](https://github.com/v2matosevic/gpt-image-tool/blob/v0.5.0/docs/SETUP.md#upgrade-an-existing-installation), then reconnect MCP. No global install is required.

With `OPENAI_API_KEY` set in the launching environment:

```sh
node dist/cli.js "an orange paper bird" --backend apikey --image-model flare --quality low -o draft.png
node dist/cli.js --edit draft.png --instruction "Make the paper blue" --backend apikey --image-model sunburst --quality high -o final.png
```

MCP uses `backend: "apikey"` with `image_model: "flare"` or `"sunburst"`. Profiles use `imageModel`. API calls have separate billing; merely upgrading does not select the API backend. `GPT_IMAGE_API_MODEL` remains the global API renderer override. `GPT_IMAGE_MODEL` still names the subscription director, not an image renderer.

## Verification and limits

All 97 offline tests and the real MCP smoke passed locally, including model forwarding, quality, profiles, replay, references/masks, real CLI subprocesses and the no-fallback boundary. Tests mock provider responses and spend no image quota. Three live subscription probes established the selection limitation; they did not verify either renderer's identity. No paid API generation was performed because the task environment had no API key.

Read the [system analysis and research](https://github.com/v2matosevic/gpt-image-tool/blob/v0.5.0/docs/IMAGE-2.5-RESEARCH.md) and [release verification](https://github.com/v2matosevic/gpt-image-tool/blob/main/docs/RELEASE-VERIFICATION.md) for exact evidence, clean-install checks, CI and publication status.
